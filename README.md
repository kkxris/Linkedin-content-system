# LinkedIn Content System

An AI-powered LinkedIn content system for Vidushi Malhan, structured around four core files: About Me (identity and credibility), Strategy (audience, pillars and content direction), Voice (tone, hooks and writing rules), and Feedback (performance insights and improvements).

Workflow: About Me + Strategy define what to create → Voice guides how to write it → drafts are generated and reviewed → Feedback captures learnings from results → insights refine future content.

The repository keeps the system's context, writing rules and learning loop organised so content stays consistent, relevant and improves over time.
